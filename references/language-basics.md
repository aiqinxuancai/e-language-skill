## 语言与运行模型

易语言是以中文标识符和命令为主要表达方式的 Windows 开发语言。经典易语言 IDE 把源码、窗口、资源、依赖和编辑信息存入二进制 `.e`/`.ec` 工程。外部看到的 `.txt` 通常是 IDE 或 e-packager 导出的文本表示，不是官方原生源码文件。

以 `.` 开头的行是结构指令，例如 `.程序集`、`.子程序`、`.参数`、`.局部变量`、`.如果`。普通中文命令大多来自核心支持库、扩展支持库、易模块或项目自身，必须查询当前依赖后再调用。

## 标识符、注释和空白

- 标识符可使用中文、拉丁字母、数字和下划线；不要假定大小写能可靠区分同名项。
- 单引号 `'` 开始行注释或尾部注释；不要改成 `//`、`/* */`。
- 保留原项目缩进风格。IDE 可能重新格式化部分空白或全/半角符号，不要把等价换形误判为业务修改。
- 普通程序集及窗口程序集中的子程序名通常按全工程解析，没有 C++ 命名空间式隔离。

## 常用数据类型

常见内置类型包括：

- `字节型`、`短整数型`、`整数型`、`长整数型`
- `小数型`、`双精度小数型`
- `逻辑型`
- `日期时间型`
- `文本型`
- `字节集`
- `子程序指针`
- `通用型`

工程还可使用自定义数据类型、类、窗口/组件类型，以及支持库公开的数据类型。遇到陌生类型时先搜索 `.数据类型`、`elib/`、`ecom/` 和 `header/`，不要擅自替换为近似内置类型。

变量声明后由易语言按类型提供默认值：数值为 0、逻辑为假、文本为空文本；对象或类变量通常也不需要写 `变量 ＝ 类型名`。只有需要非默认值或重置状态时才赋值。

## 字面量与特殊前缀

- 文本字面量使用易语言/IDE 接受的引号形式。生成新表达式时优先使用中文弯引号 `“文本”`；对已读取的源码保留原引号形式。声明中的数组维数字段常表现为 ASCII 引号，例如 `"0"`。
- `真`、`假` 是逻辑值。
- 数值可包含正负号和小数；不要加入其他语言的类型后缀。
- 日期时间文本表示可形如 `[2026年7月22日]` 或带时分秒；使用前应以当前工程/支持库行为为准。
- `#名称` 引用常量或资源；`#类型.成员` 可表示枚举成员。
- `&子程序名` 表示取子程序地址，常用于回调；参数需要整数地址时常见 `到整数 (&回调子程序)`，但必须核对目标位数与签名。
- `{ ... }` 是字节型数组字面量。需要在参数或其他表达式位置作为字节集使用时，显式写 `到字节集 ({ ... })`。

## 表达式与调用

典型形式：

```text
结果 ＝ 子程序名 (参数1, 参数2)
对象.方法名 (参数)
值 ＝ 对象.成员
元素 ＝ 数组 [索引]
```

注意：

- 赋值与相等判断在 IDE 文本中都常写 `＝`，由所在语句/表达式位置解释；不要机械替换为 `=` 或 `==`。
- 常用算术符号可能显示为 `＋`、`－`、`×`、`÷`、`\`、`％`；保留当前工程风格。
- 比较可见 `≠`、`＜`、`＞`、`≤`、`≥`、`≈` 等形式。
- 逻辑组合使用 `且`、`或` 等易语言表达，不写 `&&`、`||`，除非原文本和工具链明确使用该等价形式。
- 逻辑取反常写 `非 条件` 或项目/支持库提供的等价形式；确认实际语法后再生成，不要套用 `!条件`。
- 调用允许空参数槽，例如 `命令 (值, , )`。不要删除中间空参数或把后续参数左移。
- 易语言字符串通常不使用 C 风格 `\n`、`\t` 转义；需要换行等字符时使用当前支持库提供的常量/命令并核实名称。

## 数组

- 易语言数组通常从 1 开始索引。
- 声明文本中的数组维数字段常用引号包裹：`"0"` 表示动态数组，`"10"` 表示固定 10 项，`"2,3"` 表示多维数组。
- 遍历数组常见 `.计次循环首 (取数组成员数 (数组), i)`，随后访问 `数组 [i]`。
- `清除数组`、`重定义数组`、`加入成员`、`插入成员`、`删除成员`、`取数组成员数` 等是支持库命令，不是语法关键字；调用前核对当前版本签名。
- 子程序不要把数组作为普通返回值返回。使用带 `参考 数组` 属性的输出参数，必要时另行返回数量或成功状态。
- 区分“字节型数组”和“字节集”。字面量 `{ ... }` 在不同表达式位置可能需要 `到字节集` 转换。

## 控制流

### 单分支

```text
.如果真 (条件)
    处理 ()
.如果真结束
```

`.如果真` 没有 `.否则`。需要 else 时改用 `.如果`。

### 双分支

```text
.如果 (条件)
    条件成立 ()
.否则
    条件不成立 ()
.如果结束
```

不得用 `.如果真结束` 闭合 `.如果`，也不得在 `.如果真` 中插入 `.否则`。

### 多路判断

```text
.判断开始 (值)
.判断 (1)
    处理一 ()
.判断 (2)
    处理二 ()
.默认
    处理默认 ()
.判断结束
```

### 循环

```text
.计次循环首 (次数, i)
    处理 (i)
.计次循环尾 ()

.变量循环首 (起始值, 结束值, 步长, i)
    处理 (i)
.变量循环尾 ()

.判断循环首 (继续条件)
    处理 ()
.判断循环尾 ()

.循环判断首 ()
    处理 ()
.循环判断尾 (继续条件)
```

- 使用 `跳出循环 ()` 提前结束循环。
- 使用 `到循环尾 ()` 跳过本轮剩余语句。
- 每个开始指令必须由同类结束指令闭合，禁止交叉闭合。

## 子程序语义

- 用 `返回 (值)` 返回结果；无返回值子程序可按现有风格省略或使用空返回形式，不要写 `return`。
- 参数可包含 `参考`/`传址`、`可空`、`数组` 属性。修改调用方变量或输出数组时必须正确使用参考属性。
- 声明顺序固定为参数、局部变量、执行语句。执行语句开始后不能再声明变量。
- 类方法是否能从类外调用由 `.子程序` 的公开字段决定。

## 易错的跨语言迁移习惯

禁止直接移植以下写法：

- `if (...) {}`、`switch/case`、`for`、`while`、`break`、`continue`
- `return value;`
- `new Type()`、构造器赋值、`this.`、`self.`、`super.`
- 零基数组和 `< length`
- C/JSON 字符串转义
- 依靠方法重载、覆盖、接口多态或命名空间消除重名
