## 语言与运行模型

易语言是以中文标识符和命令为主要表达方式的 Windows 开发语言。经典易语言 IDE 把源码、窗口、资源、依赖和编辑信息存入二进制 `.e`/`.ec` 工程。外部看到的 `.txt` 通常是 IDE 或 e-packager 导出的文本表示，不是官方原生源码文件。

以 `.` 开头的行是结构指令，例如 `.程序集`、`.子程序`、`.参数`、`.局部变量`、`.如果`。普通中文命令大多来自核心支持库、扩展支持库、易模块或项目自身，必须查询当前依赖后再调用。

## 程序入口

### 标准入口 `_启动子程序`

`_启动子程序` 是易语言的标准程序入口，地位相当于 C/C++ 的 `main`。它写在普通程序集中，通常声明为整数型返回值并以 `返回 (0)` 结束：

```text
.版本 2

.程序集 程序集1

.子程序 _启动子程序, 整数型

' 程序主体
返回 (0)
```

返回值字段也可留空。控制台程序、DLL 之外的纯逻辑程序和大部分非窗口程序都从这里开始执行。

### 窗口程序的入口优先级

窗口程序不一定需要 `_启动子程序`。IDE 新建窗口程序时默认存在名为 `_启动窗口` 的窗口，此时：

- 存在 `_启动窗口` 时，程序直接优先载入该窗口，**无视 `_启动子程序`**（即使已经写了 `_启动子程序` 也不会执行）。
- 用户可以主动改造为代码入口：把 `_启动窗口` 改成其他名称（例如 `主窗口`），再新增 `_启动子程序`，并在其中显式载入窗口。

显式载入窗口的写法：

```text
.子程序 _启动子程序, 整数型

载入 (主窗口, , 假)
返回 (0)
```

`载入` 的第三个参数为 `假` 表示非模式（非阻塞）载入，由窗口自身的消息循环维持程序运行；为 `真` 则表示模式载入，会阻塞在该调用处直到窗口关闭。改造入口前先确认工程内是否仍有其他代码或资源依赖原窗口名。

黑月界面类程序同样使用这条代码入口，但不载入易语言窗口：新建 Windows 窗口程序后删除 `_启动窗口`，在 `_启动子程序` 中初始化 `应用程序类` 并由它提供唯一消息循环。不要在易语言可视化窗口的创建完毕事件里做这件事，那会在一个原生窗口内部再套一层消息循环。见 [blackmoon.md](blackmoon.md) 的「程序入口与工程类型」。

判断当前工程入口时，按以下顺序确认，不要只看是否存在 `_启动子程序`：

1. 是否存在名为 `_启动窗口` 的窗口程序集；存在则它是实际入口。
2. 否则查找普通程序集中的 `_启动子程序`。
3. 模块（`.ec`）与 DLL 另有约定，见下文。

### 易模块（`.ec`）中的 `_启动子程序`

易模块同样可以包含 `_启动子程序`。它在模块被当作独立工程编译时作为入口，被主工程引用时通常不作为主程序入口执行；模块的对外能力仍由其公开子程序决定。这一点让模块可以自带自测入口：需要单独验证模块逻辑时，把模块工程显式编译为控制台 EXE 即可运行 `_启动子程序`。

DLL 工程的入口约定与 EXE 不同；黑月 DLL 使用 `Dll入口函数`，详见 [blackmoon.md](blackmoon.md)。

### 用 `_启动子程序` 做编译验证

需要验证语法、支持库签名或某段逻辑的实际行为时，最省事的做法是在 `_启动子程序` 中直接写测试代码或调用待验证的子程序，并用 `标准输出` 把结果打印到控制台：

```text
.子程序 _启动子程序, 整数型

标准输出 (, “结果=” + 到文本 (待验证子程序 (1, 2)))
返回 (0)
```

`标准输出` 需要控制台环境才能看到输出，因此验证时应把工程编译为控制台 EXE。它是核心支持库命令而非语法结构，首个槽位为输出方式，生成前按当前工程的核心库确认实际参数与空槽含义。用 AutoLinker 编译验证的具体参数见 [autolinker-headless-compile.md](autolinker-headless-compile.md) 与 [autolinker-mcp.md](autolinker-mcp.md)。验证用的临时代码属于调试脚手架，任务结束前应还原或明确告知用户。

## 标识符、注释和空白

- 标识符可使用中文、拉丁字母、数字和下划线；不要假定大小写能可靠区分同名项。
- 单引号 `'` 开始行注释或尾部注释；不要改成 `//`、`/* */`。
- 保留原项目缩进风格。IDE 可能重新格式化部分空白或全/半角符号，不要把等价换形误判为业务修改。
- 普通程序集及窗口程序集中的子程序名通常按全工程解析，没有 C++ 命名空间式隔离。

## 常用数据类型

常见内置类型包括：

- `字节型`、`短整数型`、`整数型`、`长整数型`
- `小数型`、`双精度小数型`
- `逻辑型`
- `日期时间型`
- `文本型`
- `字节集`
- `子程序指针`
- `通用型`

工程还可使用自定义数据类型、类、窗口/组件类型，以及支持库公开的数据类型。遇到陌生类型时先搜索 `.数据类型`、`elib/`、`ecom/` 和 `header/`，不要擅自替换为近似内置类型。

变量声明后由易语言按类型提供默认值：数值为 0、逻辑为假、文本为空文本；对象或类变量通常也不需要写 `变量 ＝ 类型名`。只有需要非默认值或重置状态时才赋值。

## 字面量与特殊前缀

- 文本字面量使用易语言/IDE 接受的引号形式。生成新表达式时优先使用中文弯引号 `“文本”`；对已读取的源码保留原引号形式。声明中的数组维数字段常表现为 ASCII 引号，例如 `"0"`。
- `真`、`假` 是逻辑值。
- 数值可包含正负号和小数；不要加入其他语言的类型后缀。
- 日期时间文本表示可形如 `[2026年7月22日]` 或带时分秒；使用前应以当前工程/支持库行为为准。
- `#名称` 引用常量或资源；`#类型.成员` 可表示枚举成员。
- `&子程序名` 表示取子程序地址，常用于回调；参数需要整数地址时常见 `到整数 (&回调子程序)`，但必须核对目标位数与签名。
- `{ ... }` 是字节型数组字面量。需要在参数或其他表达式位置作为字节集使用时，显式写 `到字节集 ({ ... })`。

## 表达式与调用

典型形式：

```text
结果 ＝ 子程序名 (参数1, 参数2)
对象.方法名 (参数)
值 ＝ 对象.成员
元素 ＝ 数组 [索引]
```

注意：

- 赋值与相等判断在 IDE 文本中都常写 `＝`，由所在语句/表达式位置解释；不要机械替换为 `=` 或 `==`。
- 常用算术符号可能显示为 `＋`、`－`、`×`、`÷`、`\`、`％`；保留当前工程风格。
- 比较可见 `≠`、`＜`、`＞`、`≤`、`≥`、`≈` 等形式。
- 逻辑组合使用 `且`、`或` 等易语言表达，不写 `&&`、`||`，除非原文本和工具链明确使用该等价形式。
- 逻辑取反常写 `非 条件` 或项目/支持库提供的等价形式；确认实际语法后再生成，不要套用 `!条件`。
- 调用允许空参数槽，例如 `命令 (值, , )`。不要删除中间空参数或把后续参数左移。
- 易语言字符串通常不使用 C 风格 `\n`、`\t` 转义；需要换行等字符时使用当前支持库提供的常量/命令并核实名称。

## 数组

- 易语言数组通常从 1 开始索引。
- 声明文本中的数组维数字段常用引号包裹：`"0"` 表示动态数组，`"10"` 表示固定 10 项，`"2,3"` 表示多维数组。
- 遍历数组常见 `.计次循环首 (取数组成员数 (数组), i)`，随后访问 `数组 [i]`。
- `清除数组`、`重定义数组`、`加入成员`、`插入成员`、`删除成员`、`取数组成员数` 等是支持库命令，不是语法关键字；调用前核对当前版本签名。
- 子程序不要把数组作为普通返回值返回。使用带 `参考 数组` 属性的输出参数，必要时另行返回数量或成功状态。
- 区分“字节型数组”和“字节集”。字面量 `{ ... }` 在不同表达式位置可能需要 `到字节集` 转换。

## 控制流

### 单分支

```text
.如果真 (条件)
    处理 ()
.如果真结束
```

`.如果真` 没有 `.否则`。需要 else 时改用 `.如果`。

### 双分支

```text
.如果 (条件)
    条件成立 ()
.否则
    条件不成立 ()
.如果结束
```

不得用 `.如果真结束` 闭合 `.如果`，也不得在 `.如果真` 中插入 `.否则`。

### 多路判断

```text
.判断开始 (值)
.判断 (1)
    处理一 ()
.判断 (2)
    处理二 ()
.默认
    处理默认 ()
.判断结束
```

### 循环

```text
.计次循环首 (次数, i)
    处理 (i)
.计次循环尾 ()

.变量循环首 (起始值, 结束值, 步长, i)
    处理 (i)
.变量循环尾 ()

.判断循环首 (继续条件)
    处理 ()
.判断循环尾 ()

.循环判断首 ()
    处理 ()
.循环判断尾 (继续条件)
```

- 使用 `跳出循环 ()` 提前结束循环。
- 使用 `到循环尾 ()` 跳过本轮剩余语句。
- 每个开始指令必须由同类结束指令闭合，禁止交叉闭合。

## 子程序语义

- 用 `返回 (值)` 返回结果；无返回值子程序可按现有风格省略或使用空返回形式，不要写 `return`。
- 参数可包含 `参考`/`传址`、`可空`、`数组` 属性。修改调用方变量或输出数组时必须正确使用参考属性。
- 声明顺序固定为参数、局部变量、执行语句。执行语句开始后不能再声明变量。
- 类方法是否能从类外调用由 `.子程序` 的公开字段决定。

## 易错的跨语言迁移习惯

禁止直接移植以下写法：

- `if (...) {}`、`switch/case`、`for`、`while`、`break`、`continue`
- `return value;`
- `new Type()`、构造器赋值、`this.`、`self.`、`super.`
- 零基数组和 `< length`
- C/JSON 字符串转义
- 依靠方法重载、覆盖、接口多态或命名空间消除重名

先表达语义，再用已确认存在的易语言结构和支持库命令实现。
