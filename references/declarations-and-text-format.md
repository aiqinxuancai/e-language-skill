## 文本格式的性质

`.e`/`.ec` 是二进制工程。`src/*.txt` 是 e-packager 或 IDE 桥接层生成的结构化文本。逗号分隔的是固定字段槽位，而不是可随意压缩的 CSV。只可省略行尾未使用槽位；中间空槽必须保留。

普通字符串或说明文字中的逗号不一定是结构分隔符。`.程序集`、`.子程序` 等行以前三个结构逗号为字段边界，第三个逗号后的内容均属于说明文字。

`.版本 2` 是常见页头版本标记；`.支持库` 是依赖声明，不是可以随意复制的普通注释。某些 IDE 版本把窗口页导出为 `.窗口程序集`，另一些路径会以带 `窗口:` 基类/页标识的 `.程序集` 表示；以当前真实页为准。

## 页面结构

常见代码页：

```text
.版本 2

.程序集 程序集名
.程序集变量 ...

.子程序 子程序名, 返回类型, 公开属性, 说明
.参数 ...
.局部变量 ...

执行语句
```

局部修改不要重复插入 `.版本 2`。窗口程序集或某些 IDE 读回形式的头部可能不同，应保留真实页现状，不要强制改成普通程序集。

## 固定字段总表

| 指令 | 固定字段顺序 | 关键约束 |
| --- | --- | --- |
| `.程序集` | 名称, 基类, 公开属性, 说明 | 公开属性仅为空或 `公开` |
| `.窗口程序集` | 窗口页标识（具体导出形态随 IDE 版本） | 必须保留窗口与代码页绑定，不要将其当普通程序集改写 |
| `.子程序` | 名称, 返回类型, 公开属性, 说明 | 第 3 字段不能放说明 |
| `.参数` | 名称, 类型, 参数属性, 说明 | 属性可组合 `参考/传址`、`可空`、`数组` |
| `.局部变量` | 名称, 类型, 静态属性, 数组维数, 说明 | 第 3 字段仅为空或 `静态` |
| `.程序集变量` | 名称, 类型, 保留空槽, 数组维数, 说明 | 第 3 字段必须为空，不是静态属性 |
| `.全局变量` | 名称, 类型, 公开属性, 数组维数, 说明 | 第 3 字段仅为空或 `公开` |
| `.数据类型` | 名称, 公开属性, 说明 | 后接 `.成员` |
| `.成员` | 名称, 类型, 传址属性, 数组维数, 说明 | 第 3 字段按需为 `传址` |
| `.DLL命令` | 名称, 返回类型, DLL 名, 入口名, 公开属性, 说明 | 保留 DLL/入口名空槽 |
| `.常量` | 名称, 值, 公开属性, 说明 | 二进制/长文本资源可能由资源表管理 |
| `.支持库` | 支持库名称/版本信息（项目指令） | 只在明确添加依赖时修改，名称必须来自当前安装库 |
| `.图片` / `.声音` / `.长文本` | 资源名称, 公开属性, 说明 | 资源索引和二进制内容必须同步维护 |

## 程序集与类

```text
.程序集 String, , , 字符串处理程序集
.程序集 DateTimeEx, BaseDateTime, 公开, 日期时间类
```

- 无基类、非公开但有说明时必须保留三个逗号。
- `<对象>` 是默认对象基类的可能导出标记；IDE 有时将其视为省略基类的等价形式。不要仅为格式统一改写。
- 类对外方法必须在子程序第 3 字段填写 `公开`；内部辅助方法保持私有。
- 类通常包含 `_初始化`、`_销毁` 生命周期子程序。新增类时保留 IDE 创建的生命周期结构和顺序。
- 易语言类不按现代 OOP 方式提供可靠的方法覆盖/重写/多态。调用父类实现通常直接调用父类方法名；不要生成 `super.`。

## 子程序、参数与变量

```text
.子程序 查找记录, 整数型, 公开, 返回符合条件的数量
.参数 关键字, 文本型, , 要查找的文本
.参数 结果, 文本型, 参考 数组, 输出结果数组
.局部变量 i, 整数型
.局部变量 临时文本, 文本型, 静态, , 跨调用保留
.局部变量 索引, 整数型, , "0", 动态数组

返回 (0)
```

顺序规则：

1. 连续声明所有 `.参数`。
2. 连续声明所有 `.局部变量`。
3. 再写注释、赋值、调用和控制流。

以下写法错误：

```text
.子程序 方法1, , 这是说明
```

说明被错误放进了第 3 字段。正确写法：

```text
.子程序 方法1, , , 这是说明
```

程序集变量的第 3 槽必须为空：

```text
.程序集变量 m_int, 整数型, , "0", 动态整数数组
```

不要写成：

```text
.程序集变量 m_int, 整数型, "0", 动态整数数组
```

## 自定义数据类型

```text
.数据类型 POINT_EX, 公开, 坐标结构
.成员 x, 整数型
.成员 y, 整数型
.成员 buffer, 字节型, , "16", 固定缓冲区
```

自定义数据类型用于结构化数据和 DLL 互操作时，要核对字段顺序、类型宽度、数组长度、传址方式和目标 API 的内存布局。不要为了“更现代”而重排成员。

## DLL 命令

```text
.DLL命令 MessageBoxW, 整数型, "user32.dll", "MessageBoxW", 公开, 显示消息框
.参数 hWnd, 整数型
.参数 lpText, 文本型
.参数 lpCaption, 文本型
.参数 uType, 整数型
```

字段必须与真实导出匹配。若 DLL 名或入口名省略，仍要保留后续字段所需的中间逗号。参数的传值/传址、文本编码、指针宽度、回调约定和结构布局属于 ABI，不能仅凭名称猜测。

## 常量与资源

- `.常量` 表示普通常量声明；代码通过 `#常量名` 引用。
- 图片、声音、长文本和任意二进制资源也可能作为资源常量存在。
- e-packager 通常在 `image/list.json`、`audio/list.json` 等索引中管理二进制资源；使用其 `update --add-image/--add-audio` 流程，不要只复制文件而遗漏索引。
- AutoLinker 的固定常量表可能包含无法可靠覆盖的长文本/二进制内容。除非明确需要并确认工具支持，优先避免整体重写常量表。

## 格式保护规则

- 保留中间空字段、参数空位、数组维数和说明。
- 区分普通引号、中文弯引号与声明维数字段中的引号；不做全文件字符替换。
- 不把 `.程序集变量` 当成 `.局部变量` 随意改写；IDE 桥接层可能内部转换，但外部 Agent 应使用工具要求的公开格式。
- 不修改只读的窗口 XML、依赖导出文本或封包元数据。
- IDE 可能省略控制指令前导点、补空 `.否则/.默认` 或调整页头。比较业务变化时使用结构化差异/归一化结果，不以字节完全相同作为唯一标准。
