# 易语言代码模式与反例

## 目录

- 最小子程序
- 参数和局部变量
- 数组输出参数
- 条件与循环
- 类公开方法
- DLL 与结构声明
- 窗口事件拆分

示例用于说明结构，不保证示例中的业务命令来自当前工程。实际使用任何普通命令前，先查询项目与依赖公开接口。

## 最小子程序

```text
.版本 2

.程序集 工具程序集

.子程序 取固定值, 整数型, 公开, 返回示例数值

返回 (1)
```

只插入子程序时通常不要包含 `.版本` 和 `.程序集` 头。

## 参数和局部变量

```text
.子程序 处理文本, 逻辑型, 公开, 处理输入并返回是否成功
.参数 输入文本, 文本型, , 待处理内容
.参数 输出文本, 文本型, 参考, 处理结果
.局部变量 临时文本, 文本型

.如果真 (输入文本 ＝ “”) 
    返回 (假)
.如果真结束

临时文本 ＝ 输入文本
输出文本 ＝ 临时文本
返回 (真)
```

重点：参数在前、局部变量居中、执行语句在后；不为 `临时文本` 生成冗余空文本初始化。

## 数组输出参数

```text
.子程序 生成序号, 整数型, 公开, 通过参考数组返回序号
.参数 数量, 整数型
.参数 结果, 整数型, 参考 数组, 输出数组
.局部变量 i, 整数型

清除数组 (结果)
.计次循环首 (数量, i)
    加入成员 (结果, i)
.计次循环尾 ()
返回 (取数组成员数 (结果))
```

先确认 `清除数组`、`加入成员`、`取数组成员数` 在当前核心库中的签名。

## 条件与循环

```text
.如果 (分数 ≥ 60)
    结果 ＝ “通过”
.否则
    结果 ＝ “未通过”
.如果结束

.变量循环首 (1, 取数组成员数 (数据), 1, i)
    .如果真 (数据 [i] ＝ 目标)
        跳出循环 ()
    .如果真结束
.变量循环尾 ()
```

## 类公开方法

```text
.版本 2

.程序集 计数器, , 公开, 简单计数类
.程序集变量 m_value, 整数型, , , 当前值

.子程序 _初始化

.子程序 _销毁

.子程序 增加, , 公开, 增加计数
.参数 增量, 整数型

m_value ＝ m_value ＋ 增量

.子程序 取当前值, 整数型, 公开

返回 (m_value)
```

外部 API 填写 `公开`；生命周期方法及内部辅助方法按 IDE/项目现状保留。

## DLL 与结构声明

```text
.数据类型 POINT_EX, 公开, 二维坐标
.成员 x, 整数型
.成员 y, 整数型

.DLL命令 ClientToScreen, 逻辑型, "user32.dll", "ClientToScreen", 公开
.参数 hWnd, 整数型
.参数 lpPoint, POINT_EX, 传址
```

这只展示声明形状。实际返回类型、参数属性、入口名、编码和指针宽度必须以目标头文件及当前易语言 ABI 为准。

## 窗口事件拆分

```text
.子程序 _按钮保存_被单击

执行保存 ()

.子程序 执行保存, 逻辑型, , 窗口内部保存逻辑

' 读取控件、校验并保存
返回 (真)
```

事件仍在原窗口程序集。若 `执行保存` 需要跨程序集复用，应使用全工程唯一名称、正确页面和公开策略，并避免让普通程序集直接依赖窗口控件。

## 常见反例

### 错误的双分支

```text
.如果真 (条件)
.否则
.如果结束
```

改为 `.如果` / `.否则` / `.如果结束`。

### 错误的字段压缩

```text
.子程序 方法, , 说明
.程序集变量 数据, 文本型, "0", 说明
```

改为：

```text
.子程序 方法, , , 说明
.程序集变量 数据, 文本型, , "0", 说明
```

### 错误的声明顺序

```text
.子程序 方法
.局部变量 临时值, 整数型
.参数 输入值, 整数型
```

参数必须出现在所有局部变量之前。

### 错误的其他语言语法

```text
if (ok) {
    return value;
}
```

改用 `.如果真` 和 `返回 (...)`，并使用已确认的易语言表达式。

### 错误的命令臆造

```text
文本 ＝ 字符串.去除空白并转小写 ()
```

除非当前类或依赖确实公开该方法，否则先搜索实际可用的文本处理命令，再组合实现。
